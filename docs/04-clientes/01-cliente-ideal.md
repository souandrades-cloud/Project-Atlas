# Cliente Ideal do Project Atlas

## Primeiro Mercado

O primeiro mercado escolhido pelo Project Atlas será o segmento de clínicas e profissionais da saúde.

---

# Perfil do Cliente

O cliente ideal possui:

- uma clínica ou consultório em funcionamento;
- necessidade de atrair mais pacientes;
- interesse em melhorar processos;
- disposição para utilizar tecnologia.

---

# Principais Dores

Os clientes enfrentam problemas como:

- dificuldade para atrair novos pacientes;
- presença digital pouco profissional;
- demora no atendimento;
- perda de oportunidades;
- excesso de tarefas manuais.

---

# Objetivos do Cliente

O cliente deseja:

- aumentar o número de contatos;
- melhorar o atendimento;
- economizar tempo;
- transmitir mais profissionalismo;
- organizar sua operação.

---

# Solução Atlas

O Project Atlas ajuda através de:

- páginas digitais profissionais;
- automações de atendimento;
- organização de contatos;
- inteligência artificial aplicada;
- melhoria de processos.

---

# Comunicação da Oferta

O Atlas não vende tecnologia.

O Atlas vende:

"Uma estrutura digital inteligente para ajudar clínicas a conquistar mais oportunidades e trabalhar de forma mais eficiente."

---

# Critério de Qualificação

Um cliente ideal deve possuir:

- problema claro;
- capacidade de investimento;
- interesse em crescimento;
- abertura para inovação.

---

# Visão de Evolução

Após validar o modelo com clínicas, o Project Atlas poderá expandir para outros segmentos profissionais.
