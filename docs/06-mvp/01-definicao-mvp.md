# Definição do MVP Project Atlas

## Objetivo

O MVP do Project Atlas representa a primeira versão funcional da solução que será entregue para clientes reais.

O objetivo é validar o modelo de negócio antes de construir uma plataforma completa.

---

# Nome do MVP

Atlas Atendimento Inteligente

---

# Problema Resolvido

Clínicas perdem oportunidades porque:

- demoram para responder contatos;
- não organizam informações;
- possuem processos manuais;
- não acompanham potenciais pacientes.

---

# Solução

O Atlas cria um fluxo inteligente capaz de:

- receber contatos;
- organizar informações;
- responder dúvidas iniciais;
- qualificar oportunidades;
- encaminhar informações.

---

# Fluxo do MVP

Contato

↓

Entrada de dados

↓

Automação n8n

↓

Agente de IA

↓

Banco de dados

↓

Resposta ou encaminhamento

---

# Tecnologias Iniciais

- n8n;
- APIs de Inteligência Artificial;
- Banco de dados;
- Landing page;
- GitHub;
- Claude Code.

---

# Critério de Sucesso

O MVP será considerado validado quando conseguir:

- funcionar para um cliente real;
- economizar tempo;
- organizar contatos;
- gerar valor percebido.

---

# Evolução Futura

Após validação, o sistema poderá evoluir para:

- múltiplos agentes;
- dashboards;
- integrações;
- plataforma própria.
