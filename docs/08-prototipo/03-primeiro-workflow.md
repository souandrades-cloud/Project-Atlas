# Primeiro Workflow do Project Atlas

## Objetivo

Criar o primeiro fluxo funcional utilizando n8n.

Este fluxo tem como objetivo validar o funcionamento da automação dentro do ambiente Atlas.

---

# Primeiro Teste

O primeiro workflow será simples:

Entrada manual

↓

Processamento

↓

Resultado

---

# Componentes

## Manual Trigger

Responsável por iniciar o fluxo manualmente.

---

## Set Node

Responsável por criar e manipular informações.

---

# Resultado Esperado

O sistema deve conseguir:

- receber uma informação;
- processar o dado;
- retornar um resultado.

---

# Evolução

Este fluxo será futuramente expandido com:

- APIs de Inteligência Artificial;
- agentes;
- banco de dados;
- integrações externas.
