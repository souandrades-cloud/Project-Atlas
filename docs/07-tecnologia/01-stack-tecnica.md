# Stack Técnica do MVP Project Atlas

## Objetivo

Definir as tecnologias utilizadas para construir a primeira versão funcional do Project Atlas.

A escolha das ferramentas deve considerar simplicidade, evolução e capacidade de escala.

---

# Camadas do Sistema

## Interface

Responsável pela interação com usuários.

Possíveis tecnologias:

- HTML;
- CSS;
- JavaScript;
- React;
- Next.js.

---

# Automação

Ferramenta principal:

n8n

Responsável por:

- conectar sistemas;
- executar fluxos;
- integrar APIs.

---

# Inteligência Artificial

Responsável por:

- análise;
- respostas;
- decisões automatizadas.

Componentes:

- modelos de IA;
- agentes inteligentes;
- APIs.

---

# Banco de Dados

Responsável por armazenar:

- usuários;
- clientes;
- mensagens;
- histórico.

Tecnologia inicial:

PostgreSQL.

---

# Desenvolvimento

Ferramentas:

- Antigravity IDE;
- Claude Code;
- GitHub.

---

# Princípio Técnico

O sistema deve ser construído de forma modular.

Cada componente deve possuir uma responsabilidade clara e permitir evolução futura.
