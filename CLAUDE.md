# Project Atlas - Guia de Desenvolvimento

## Contexto do Projeto

Você está trabalhando no Project Atlas.

O Project Atlas é um sistema operacional interno criado para organizar e automatizar uma empresa de soluções digitais.

O sistema centraliza:

- clientes;
- projetos;
- tarefas;
- documentos;
- financeiro;
- automações;
- inteligência artificial.

---

# Regra Principal

Antes de criar qualquer funcionalidade, entenda:

1. Qual problema essa funcionalidade resolve?
2. Quem utilizará essa funcionalidade?
3. Como ela se conecta ao restante do sistema?
4. Existe documentação sobre essa decisão?

Nenhuma funcionalidade deve ser criada sem um objetivo claro.

---

# Filosofia de Desenvolvimento

O projeto segue cinco princípios:

## 1. Simplicidade

Sempre escolher soluções fáceis de entender, manter e evoluir.

## 2. Organização

Cada informação deve possuir um local definido.

## 3. Escalabilidade

O sistema deve ser construído pensando no crescimento futuro.

## 4. Reutilização

Evitar criar soluções descartáveis.

## 5. Qualidade

Priorizar código limpo, organizado e documentado.

# Inteligência Artificial

A IA deve funcionar como uma assistente operacional.

Possíveis funções:

- organizar informações;
- gerar documentos;
- auxiliar decisões;
- automatizar tarefas repetitivas.

A IA nunca deve substituir processos mal definidos.

Primeiro organizamos o processo.

Depois automatizamos.
